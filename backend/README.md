# 🚚 Deliverify API

The **Deliverify API** powers the delivery management ecosystem — handling authentication, deliveries, users, and roles.

---

## 🚀 Getting Started

This package is part of the [Deliverify Monorepo](../README.md). For full installation instructions, please refer to the root README.

### Specific Scripts
- `npm start`: Runs the production server.
- `npm run dev`: Runs the server with `nodemon`.
- `npm test`: Runs the 130+ Jest test cases.

## 🔐 Security

This API uses **JWT (JSON Web Tokens)**. Protected routes require a `Bearer <token>` in the `Authorization` header.
